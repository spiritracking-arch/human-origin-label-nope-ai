# verumano demo

A tiny Vite page that uses the [`verumano`](https://www.npmjs.com/package/verumano) npm package against the live public API:

1. Look up a creator ID
2. Show the live `<verumano-badge>`
3. Hash a file locally and check whether this exact file is certified

[Open in StackBlitz](https://stackblitz.com/github/spiritracking-arch/human-origin-label-nope-ai/tree/main/examples/demo?file=main.js)

Run locally:

```bash
npm install
npm run dev
```
